# FlowMattic organisation profile

This repository holds the public profile shown at [github.com/FlowMattic](https://github.com/FlowMattic).

- `profile/README.md` is the page GitHub renders on the organisation home.
- `profile/assets/` holds the hero banner, the MCP diagram and the product icons. All are hand-written SVG, referenced by absolute raw URLs so they render on the profile.

Images use system font stacks on purpose: GitHub proxies images and blocks web fonts. Keep copy short inside the SVGs and leave room for wider fallback fonts.
