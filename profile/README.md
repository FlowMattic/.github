## Both sides of MCP

<a href="https://flowmattic.com/mcp/">
  <img src="https://raw.githubusercontent.com/FlowMattic/.github/main/profile/assets/mcp-flow.svg" alt="AI assistants call FlowMattic as an MCP server. FlowMattic calls any MCP server as a client." width="100%">
</a>

As a server, FlowMattic exposes your workflows, tables and PHP functions as tools that Claude, ChatGPT, Cursor and VS Code can call. As a client, your workflows and AI agents call tools on any MCP server, with no custom code. Since FlowMattic 7.2, an AI assistant can also build and update workflows for you over MCP.

- [How the MCP server works](https://flowmattic.com/mcp/)
- [Connect to any MCP server from a workflow](https://flowmattic.com/mcp-client/)
- [What shipped in FlowMattic 7.2](https://flowmattic.com/flowmattic-7-2/)
